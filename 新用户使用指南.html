一分钟快速开始

程序入口：第一次使用只需双击下方文件，不要进入 release 文件夹寻找程序。
解压目录\EU4_AutoSave_Assistant.exe
  1. 启动助手。主界面会显示世界地图区域、左侧功能栏和右侧国家/警告栏。
  2. 检查版本提示。看到绿色“491d 已验证”即可正常使用全部功能；其它版本请先阅读本页“版本与风险模式”。
  3. 读取存档。点击“⚡ 快速读取最新存档”，程序会从游戏存档目录和归档目录中选取最新文件；也可点击“导入存档”手工选择。
  4. 查看地图。左键拖动地图、滚轮缩放；单击省份会在右侧切换到省份所属国家。
  5. 检查警告。点击“玩家警告总览”，快速确认哪些玩家国家触发了经济警告。
  6. 需要自动存档时再连接原生桥。先进入已载入的 EU4 战局，再点击“连接原生桥”，选择周期并用“立即存档”做一次测试。

左侧功能栏

所有常用操作入口都在这里。点击地图左上角的“隐藏功能栏 ◀ / ☰ 功能栏”按钮，可以用同一个按钮关闭或重新打开。

中央地图

显示国家颜色、被占领省份和军队位置。地图是主工作区，关闭左侧栏或收起右侧栏后会自动扩大。

右侧栏

分类显示经济、科技点数、发展稳定、陆海军与完整警告信息。陆军和可用人力统一显示实际人数，海军显示舰船数与水手池。右上角“收起 ◀”可折叠，单击地图省份时会自动切换国家。

读取与解析存档

最快方式：快速读取

  1. 点击左侧“⚡ 快速读取最新存档”。
  2. 程序比较游戏存档目录和归档目录（包括子目录）。
  3. 自动读取修改时间最新的 .eu4 文件并显示地图。

适合每次存档后立即刷新战局数据。

精确方式：手工导入

  1. 点击“导入存档”。
  2. 选择一个或多个 .eu4 文件。
  3. 解析完成后，可在“当前存档”下拉框切换。

适合读取旧存档、他人发送的存档或指定时间点。

较大的后期世界存档需要解析全部国家、军队和省份。当前版本已优化范围扫描，并会从用户本地游戏资源生成和复用地图缓存；本机真实后期存档完整解析中位数约 0.94 秒、缓存地图约 0.23 秒。解析仍在后台执行，等待左侧状态文字更新即可。

联机客机自动存档

适用场景：你是联机客机，希望在不打开游戏保存菜单的情况下定期生成本地存档。首次使用请先用非关键战局测试。
  1. 先启动 EU4 并进入战局。应当已完成载入和多人同步；只停留在主菜单时不能保存。
  2. 点击“连接原生桥”。连接成功后，左侧会显示日期、载入、同步和存档状态。
  3. 选择周期。可选“仅手动”“每 3 个游戏月”“每个游戏年”“每 10 个现实分钟”。
  4. 先点击一次“立即存档”。状态栏和“归档与改名”日志显示“存档验证成功”，才说明文件确实落盘且可以解析。
  5. 需要自动整理时，打开“归档与改名”。设置战役名、归档目录，并勾选“自动归档并解析桥接生成的存档”。

成功时会发生什么

  • 助手在 EU4 主线程请求一次客机本地存档。
  • 等待新文件大小稳定，并确认它能被解析。
  • 开启自动归档时，文件会经过复制、完整性验证和原子改名，然后移入归档目录。
  • 未开启自动归档时，源文件保留在游戏存档目录，但仍会自动完成后续完整解析。
大型存档写盘时游戏可能短暂停顿。此前 491d 联机实测约半秒，实际长度由存档大小和磁盘速度决定。

单击军队圆点或盾徽查看当地各国汇总、军队总数、实际兵力、每支军队的团数和兵种；点击浮窗“×”关闭。
刷新政治地图重新生成当前存档的地图显示。

省份底色代表原主；被其它国家占领时，会在原主底色上叠加控制方斜纹。远景下每省只显示一个国家色圆点，放大后显示盾徽；同省存在多国军队时，盾徽属于当地实际兵力总和最多的国家。

国家数据窗口

  • 国家列表：集中查看玩家国家的点数、科技、收支、利息、债务、陆军和警告。
  • 国家详细分析：大窗口显示理念组、收入/支出饼图以及 ADM、DIP、MIL 历史用途明细和占比。
  • 军队总览：查看当前国家每支军队的所在地、团数、实际兵力和兵种。

玩家国家警告

  1. 导入存档后，点击左侧“玩家警告总览（数字）”。数字表示当前触发警告的玩家国家数量。
  2. 窗口中查看严重程度、TAG、玩家名、警告类型和具体说明。
  3. 双击任意一行，右侧栏会切换到该玩家国家，方便继续查看贷款和监测值。
警告触发条件含义
月支出过高上月支出大于上月收入的 2 倍当前开支相对收入明显异常，需要检查军队、顾问、要塞等支出。
利息压力严重上月实际利息大于收入的 80%，并且当前国库小于收入的 100 倍债务利息已接近吞噬收入，同时现金储备不足以忽略风险。
警告是辅助判断，不等于作弊结论，也不能替代对战争、事件和特殊玩法的人工分析。

其它分析工具

归档与改名

  • 选择一个或多个待归档存档。
  • 设置战役名和目标目录。
  • 默认命名为 TAG_游戏日期_四位序号.eu4，例如 TUR_1445-3-2_0001.eu4。
  • 先点击“预览命名”，确认目标路径。
  • 点击“执行安全归档”。
  • 操作错误时可尝试“撤销最后一次归档”。

“验证成功后删除源文件（移动）”会在目标副本验证成功后移除源文件。新手首次操作建议先取消勾选。自动清理默认开启，会永久删除超过 90 天或全局超出最新 500 份的归档；重要存档请另做备份，也可在此关闭自动清理。

多存档对比

  • 点击“选择多个存档”，至少选择两份。
  • 程序要求存档内游戏版本号完全相同，不验证游戏哈希值。
  • 选择国家 TAG 和指标，即可比较国库、收支、点数、科技、理念、发展、军队及各项收入/维护支出。
  • 下方会保守列出持久事件、旗标和变量变化。

贷款计算器

  • 先在地图或国家列表中选择目标国家。
  • 点击“从当前选中国家带入”。
  • 核对月收入、普通贷款本金、3% 年利率和当前普通贷款数。
  • 点击“计算”查看估算最大贷款数、剩余额度和利息压力。

普通贷款本金优先使用存档中的正数估值，其次使用现有普通贷款最大本金，最后才使用手工输入；阶层贷款不作为普通贷款本金样本。

设置与诊断

全新安装第一次启动时，本窗口会自动弹出。请核对目录并点击“保存设置并重新检测版本”；如果直接关闭而未保存，下次启动仍会提示。旧版本已有设置的用户升级后不会重复弹出。

  • EU4 安装目录：用于版本检测、原版图标和原生桥目标验证。
  • Mod 模式：可选；选择直接包含 map、common 或 gfx 的 Mod 内容根目录。地图、国家颜色、旗帜等优先读取 Mod，缺失文件回退原版。
  • EU4 存档目录：游戏实际写入 .eu4 的位置。
  • 默认归档目录：助手整理存档的目标根目录。
  • 小窗口快捷键：默认使用 Ctrl+Shift+F9 开关、Ctrl+Shift+F10 锁定；下方会显示是否被其它程序占用。
  • 运行与崩溃日志：点击“打开报错日志目录”即可进入 logs 文件夹。

修改后必须点击“保存设置并重新检测版本”。程序会轮转保存运行日志，并为未捕获异常生成独立崩溃报告；需要维护者协助时，请发送整个 logs 文件夹。

版本与非 491d 风险模式

绿色：491d 已验证

当前游戏版本为 EU4 v1.37.5.0 Inca（491d）。自动存档、解析和界面功能均按此版本开发和测试。

红色/黄色：非 491d 高风险模式
在“设置与诊断”勾选“允许非 491d 风险模式”后，助手会允许尝试注入原生桥、自动存档、归档和解析。此选项只是放宽版本门控，不代表该版本已经兼容。
  • 可能发生游戏崩溃、联机掉线、存档失败或存档损坏。
  • 新版存档结构变化可能导致字段缺失或分析误判。
  • 原生桥内部仍会检查定位特征和保存入口；不匹配时会停止，而不会继续盲目调用。
  • 首次测试应使用非关键战局，提前备份存档，并关闭“删除源文件”。
  • 每一个非 491d 版本都需要单独实机验证；旧版本测试结果不能自动证明新版本安全。

常见问题与排查

现象优先检查
提示“未发现正在运行的 eu4.exe”先启动游戏；确认设置中的 EU4 安装目录正是当前运行游戏所在目录。
原生桥不可用确认版本提示、游戏已进入战局、安装目录正确；491d 之外还需主动启用风险模式。
点击立即存档后没有文件查看“归档与改名”日志；确认游戏已完成载入与多人同步，并检查存档目录是否正确。
快速读取的不是预期文件它会在游戏存档目录和归档目录中按修改时间选择最新文件；需要指定文件时使用“导入存档”。
铁人存档提示无法解析确认发布目录中的 native\rakaly.exe 没有被杀毒软件隔离；程序只在本机内存中解码，不会改写原始铁人存档。
小窗口快捷键无效在“设置与诊断”查看注册状态；若提示被其它程序占用，请录入其它组合并保存设置。
地图没有更新确认解析已完成，然后点击“刷新政治地图”；必要时检查游戏安装目录中的地图文件。
Mod 地图或旗帜没有生效确认已启用 Mod 模式，并且选择的是直接包含 map、common 或 gfx 的内容根目录，而不是 Workshop 的上级目录。
某国没有详细数据确认选中的存档确实包含该国家；非 491d 存档可能因结构变化缺少字段。
军队仍显示圆点继续放大地图即可切换为盾徽；单击圆点也能打开同一份当地军队明细。
归档后找不到原文件若启用了移动或自动归档，文件已移入默认归档目录；可查看日志和“撤销最后一次归档”。
程序崩溃或功能异常重新打开程序，在“设置与诊断”点击“打开报错日志目录”；将 assistant.log、轮转备份和最新的 crash_*.log 一并提供给维护者。

新用户推荐操作清单

① 确认游戏、存档与归档目录（使用 Mod 时另选内容目录）→ ② 保存设置 → ③ 导入一份已知存档 → ④ 熟悉地图与警告 → ⑤ 在非关键战局连接原生桥 → ⑥ 手动触发一次“立即存档” → ⑦ 最后再开启周期和自动归档。

程序的分析、配置、数据库和归档均保存在本机，不会自动上传存档。请始终保留关键战局的独立备份。
