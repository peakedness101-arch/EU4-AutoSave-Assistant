EU4 AutoSave Assistant 1.5.0 (491d)

1.5.0 更新：
1. 游戏时间表：可编辑日期、注意事项，前后三个月在小窗口持续提醒。
2. JSON 导入导出，导入整表替换前自动备份。
3. 新增带入日期和已有注意事项，日期采用独立上下按钮。
4. 实时游戏日期优先；无法获取实时日期时显示存档预览。

1.4.1 更新：
1. 固定小窗口宽度与切换按钮位置；长玩家 ID 以省略号显示，悬停可查看完整 ID。
2. 国家详情的理念组显示汉化中文名称，保留原学习进度；优先读取本机汉化补丁与 Mod 译名，未知键名保留原文。

1.4.0 更新：
1. 小窗口按当前省份所有权过滤变身或灭亡的旧 TAG，仍存在的 AI 接管国家可继续监视。
2. 新增本机国家军队集中警告：同省团数严格超过全国总团数 10%，且没有战争敌国陆军同省驻扎时，持续显示省份名称、ID 和团数占比。
3. 程序保存成功后先完整解析、刷新界面，再进行归档；归档关闭或失败均不妨碍分析刷新。
4. 防止重复读取、源文件移动与解析冲突、较早任务覆盖最新结果和关闭后的后台回调。
5. 警告使用存档时刻的战争双方和军队位置；不估算补给上限或实际损耗。

1.3.0 更新：
1. 小窗口重新读档后保留上次监视的国家；仅当该国已不存在时回退到本国。
2. 启动时自动检测 EU4 安装目录和存档目录，设置页可手动重新检测或覆盖。
3. 国家列表窗口显示全局 flag。
4. 国家详细分析窗口显示国家 flag 和当前君主 flag。
5. 当前君主 flag 使用 id 与 type 精确关联 history 中的 ruler_flags；缺失、空位或共和制安全留空。

目标版本：Europa Universalis IV 1.37.5.0，构建标识 491d。
非 491d 风险模式不代表兼容性保证，请先备份重要存档。
